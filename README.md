# P2P Assistant Bot

Telegram-бот помощник для P2P-трейдера: быстрый расчёт курса и прибыли,
шаблоны ответов клиенту, учёт сделок со статистикой, платная подписка
(СБП / карта — ручное подтверждение, либо Telegram Stars — автоматически)
и админ-панель.

## Возможности

- **Быстрый расчёт** — вводишь сумму, курс (вручную или подтягивается
  с Bybit P2P) и свою наценку → бот считает итоговый курс, сравнивает
  прибыль по нескольким банкам/способам оплаты и показывает лучший вариант.
- **Шаблоны ответов** — набор готовых фраз клиенту («оплатите за 15 минут»,
  «пришлите чек» и т.д.), можно добавлять свои, отправка в один тап.
- **Учёт сделок** — лог всех сделок (сумма, курс покупки/продажи, банк,
  прибыль), статистика за день/неделю/месяц.
- **Подписка** — платный доступ. Оплата картой или через СБП идёт по
  твоим реквизитам вручную, ты подтверждаешь платёж в боте по кнопке
  (как в чек-боте) — подписка активируется автоматически. Также есть
  оплата через Telegram Stars (активируется без ручного подтверждения).
- **Админ-панель** — список ожидающих платежей с подтверждением/отклонением
  в один тап, общая статистика, рассылка всем пользователям.

## Важно про оплату

СБП и приём на карту в боте реализованы как **ручное подтверждение**:
бот показывает пользователю твои реквизиты, тот переводит деньги сам
(обычным переводом в приложении банка) и присылает скриншот чека, а ты
подтверждаешь платёж кнопкой в боте. Это не настоящий эквайринг — деньги
идут напрямую тебе на карту/телефон, бот их не трогает и не обрабатывает.

Если захочешь принимать оплату автоматически (без ручной проверки чеков),
это делается через официального провайдера эквайринга (например, ЮKassa
или Т-Банк Эквайринг) — для этого нужно ИП/самозанятость и подключение
через личный кабинет провайдера. Могу помочь встроить, когда будет
готов договор с провайдером.

## Настройка

1. Скопируй `.env.example` → `.env` (или задай эти переменные как Variables
   в Railway) и заполни:
   - `BOT_TOKEN` — токен от @BotFather
   - `ADMIN_IDS` — твой Telegram user_id (можно узнать у @userinfobot),
     через запятую если админов несколько
   - `SBP_PHONE`, `SBP_BANK` — твои реквизиты СБП
   - `CARD_NUMBER`, `CARD_HOLDER` — номер карты и держатель
   - `SUBSCRIPTION_PRICE_RUB`, `SUBSCRIPTION_PRICE_STARS`, `SUBSCRIPTION_DAYS`

2. Локально:
   ```
   pip install -r requirements.txt
   python bot.py
   ```

3. Деплой на Railway — так же, как прошлый бот: залить на GitHub,
   подключить репозиторий в Railway, задать те же переменные во вкладке
   Variables, Railway сам поднимет процесс по `Procfile`.

## Структура проекта

- `bot.py` — хендлеры и запуск
- `config.py` — настройки из переменных окружения
- `storage.py` — SQLite-хранилище (пользователи, сделки, шаблоны, платежи)
- `calculator.py` — логика расчёта курса и прибыли
- `bybit_p2p.py` — получение рыночного курса с публичного API Bybit P2P
- `keyboards.py` — инлайн-клавиатуры

## Что можно докрутить дальше

- Настройка списка банков и их комиссий через бота, а не только в коде
  (`DEFAULT_BANKS` в `bot.py`)
- Реальный автоматический эквайринг (ЮKassa/Т-Банк) вместо ручного
  подтверждения чеков
- Экспорт сделок в Excel/CSV
- Индивидуальная наценка по умолчанию для каждого пользователя
